# Robinhood Dashboard Clone

A mobile-first frontend clone of the Robinhood dashboard, built with React, TypeScript, Vite, and Tailwind CSS.

## 🚀 Live Demo

The app is running at `http://localhost:5173`

## Features

- 📱 **Mobile-First Design** - Optimized for mobile devices with responsive desktop support
- 📊 **Portfolio Summary** - View total portfolio value with real-time gains/losses
- 📈 **Interactive Charts** - Recharts-powered portfolio performance visualization
- 💼 **Stock Holdings** - Detailed list of individual stock positions with performance metrics
- 💰 **Buying Power** - Display available buying power
- 🎨 **Robinhood-Inspired UI** - Clean, modern interface matching Robinhood's aesthetic
- 🧭 **Bottom Navigation** - Mobile-optimized navigation bar

## Tech Stack

- **React 19** - UI framework
- **TypeScript** - Type safety
- **Vite** - Build tool and dev server
- **Tailwind CSS** - Styling
- **React Router** - Navigation
- **Recharts** - Chart visualization
- **Lucide React** - Icons

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).
